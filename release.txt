Inverter Monitoring v1.3.2
=========================

Security and reliability
------------------------

- The deployment webhook requires a configured WEBHOOK_SECRET and a valid
  X-Hub-Signature-256 signature for the exact request body. Unsigned deliveries
  are rejected before any deployment action; /health remains available.
- Webhook logs no longer include untrusted X-GitHub-Event header values.
- The grid smoothing analyzer accepts direct HTTP/HTTPS InfluxDB endpoints and
  rejects redirects to prevent forwarding the authorization token.

Upgrade notes
-------------

Configure the same secret in the webhook service environment and GitHub webhook
settings before restarting an existing service. Missing server configuration
returns HTTP 503; a missing or invalid signature returns HTTP 401.

If the analyzer previously relied on an HTTP redirect, configure the final
InfluxDB endpoint directly. The release contains configuration files and Python
source; it does not provide a compiled binary or deploy the monitoring stack.

Validation
----------

The current source passes 60 offline tests, Ruff, MyPy, Bandit medium/high
security checks, dependency auditing, CodeQL, and Sonar analysis.

Inverter Monitoring v1.3.3
=========================

Reliability
-----------

- Dashboard restart requests now report failure when Docker returns an HTTP
  error, including missing containers and daemon failures. Error responses stay
  generic; diagnostic details remain in server logs.
- A successful restart request does not independently verify installation of
  the requested dashboard version.

Upgrade notes
-------------

The signed webhook authentication and existing release deployment policy remain
in effect. Automatic deployment stays disabled by default; the documented stable
release opt-in remains an explicit operator choice.

Validation
----------

Regression tests exercise real curl against an isolated Unix HTTP endpoint for
successful and failed Docker restart responses. No live Docker daemon or device
is used during these tests.
